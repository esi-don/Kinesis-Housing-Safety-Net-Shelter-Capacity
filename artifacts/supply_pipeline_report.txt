2. Data cleaning
Quarter labels become quarter starts. Commas are removed from numeric text. n/a and blank counts remain null. Subsidized and affordable unit counts remain separate measures.

3. Mapping to the events table
event_id: SHA256 of pipeline plus natural key (quarter start), excluding mutable counts.
source and modality: toronto_supply; constant per pipeline table.
anon_id: SHA256 of the public site identifier; no person's name.
site_id: published shelter location ID, program ID if location missing, otherwise Toronto for citywide quarterly sources.
zone: published shelter address, otherwise null.
event_time: observation date or quarter start at Toronto midnight, converted to UTC with daylight saving.
text_input: null.
payload: separately named facts; see sample JSON for each resource and source-column correspondence. Includes resourceid, sourcerow, snapshot availableat and availabilitybasis. Snapshot download time is not the original historical release date.
consent_method: public_data.
consent_scope: analytics and research.
privacy_token: public.
geo_json: null pending boundary enrichment.
ingested_at: database default, preserved on updates.
Schema is provisional pending the official KinesisIQ schema.

5. Measures
See measure_dictionary.csv for formulas, units and missing-value policies. backlog_measures.csv contains actual quarterly diagnostics. Shelter sector totals and missing_count are in data/processed/shelter_daily.csv. All statistics exclude undefined observations explicitly.

6. Conclusion
Ready to use: checksummed snapshots, validated clean tables, duplicate-safe local events and real mapped examples.
Treat as provisional: revised historical snapshots, source omissions, missing numeric facts and official schema compatibility. A repeat load updates changed facts and prunes removed keys for each loaded source, while retaining ingested_at for unchanged event IDs.
Not claimed: finer geography, waiting-time accuracy, future RGI supply, eviction correlations or operational readiness.
