1. Introduction
One source observation describes a program at a location on a date, measured in beds or rooms. This pipeline supports citywide sector forecasting. It does not measure unmet demand or users' previous neighbourhoods.

2. Data cleaning
Whitespace and numeric text are normalized. Historical YY-MM-DD dates are parsed year first; modern ISO dates are parsed separately. Missing location IDs use location=unknown and program-based site IDs. Missing counts remain null. Invalid occupancy or nonpositive actual capacity is retained and flagged; incomplete sector totals are excluded from training. Exact duplicates are collapsed; conflicting natural keys fail the run.

3. Mapping to the events table
event_id: SHA256 of pipeline plus natural key (date, program, location or explicit unknown, capacity type), excluding mutable counts.
source and modality: toronto_shelter; constant per pipeline table.
anon_id: SHA256 of the public site identifier; no person's name.
site_id: published shelter location ID, program ID if location missing, otherwise Toronto for citywide quarterly sources.
zone: published shelter address, otherwise null.
event_time: observation date or quarter start at Toronto midnight, converted to UTC with daylight saving.
text_input: null.
payload: separately named facts; see sample JSON for each resource and source-column correspondence. Includes resourceid, sourcerow, snapshot availableat and availabilitybasis. Snapshot download time is not the original historical release date.
consent_method: public_data.
consent_scope: analytics and research.
privacy_token: public.
geo_json: null pending boundary enrichment.
ingested_at: database default, preserved on updates.
Schema is provisional pending the official KinesisIQ schema.
